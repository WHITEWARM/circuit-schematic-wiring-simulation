# 可见接线与连通性检查

当创建、合并、重排原理图或检查“看起来接通但行为异常”时使用本参考。

## 可见导线是外部连接依据

使用 EDA 软件的电气导线对象，端点实际吸附并绑定元件引脚或已有导线节点。仅坐标接近、文字标注同名、普通图形线条重叠均不算连接。

信号、电源和地都绘出连续可追踪的线路。地符号可标记已经连通的公共地，电源文字可标记已经连通的电源轨；不能依赖多个分散符号的全局语义补齐图上不存在的线路。显示实际使用的电源引脚，展开隐藏供电单元。未使用引脚按数据手册处理；真正 NC 引脚可标记不连接。

不以总线名称、跨页连接符、隐藏网络或全局模型变量替代各条实际连接。模型内部局部节点和芯片内部连接属于器件实现，不需要将整颗芯片内部展开到整机图，除非任务要求使用基础器件实现。

程序化绘图可以先计算连接和路线，但最终必须创建原生导线，并由目标软件正常生成求解连接。普通改线后不能要求手动重建一套独立事件网络。

## 排布与走线

1. 先放模块，摆好输入输出朝向，为跨模块线路、电源主干和回流主干留出通道；再放局部外围元件。
2. 导线按统一网格水平或垂直布置，平行线保留可辨认间距。优先减少交叉、折返和绕远，不追求单纯最短路径。
3. 端点与引脚明确相接；T 形分支标出连接点。连接点不能落在文字下面。
4. 不同网络不能共用重合线段。确实需要交叉时保持简单正交交叉，并使用目标软件支持且含义明确的非连接表示；不能为了画跨线弧而删除原生电气导线。
5. 同一网络的共用干线只保留一次，删除重复、零长度和废弃短线。分支可以共用一条真实主干，不创建完全重合的多份导线。
6. 线不能穿过元件主体、参数或引脚文字；文字和符号也不能遮挡导线。颜色不能成为区分连接与不连接的唯一依据。
7. 空间不足先调整位置或扩大画布，不缩小到无法阅读，也不用标签取代线路。以用户要求的观看或印刷尺寸验收。

## 三份连接信息

使用稳定的外部引脚标识，例如 `U1.7`、`R3.2`。网络名或内部编号可以变化，检查的是同一网络中有哪些引脚。

- **设计连接**：按电路设计和数据手册得到的预期外部引脚分组。
- **可见连接**：从最终文件的原生导线、端点、引脚和分支构建图，求其连通分量。不利用同名标签或全局节点补边。
- **实际连接**：从目标软件打开该文件后导出的求解网表或权威网络枚举得到。还要检查模型是否绕过端口引用外部节点。

构建可见连接图时，穿越交叉点只在明确连接的情况下合并；不能把电阻两端、晶体管不同引脚或其他元件内部当作一条导线连接。所有相关外部引脚均应覆盖，悬空引脚作为单引脚网络保留，避免漏检。模型内部节点不参与外部引脚分组比较。

先比较设计与可见连接，再比较可见与实际连接。移动元件后的几何检查和连接比较都要针对最终文件，不能沿用移动前的坐标或缓存。

## 可复用比较脚本

`scripts/compare_connectivity.py` 使用 Python 3 标准库，比较两份已经提取好的外部引脚分组。输入为 UTF-8 JSON：

```json
{
  "nets": [
    {"id": "signal", "pins": ["U1.2", "R1.1"]},
    {"id": "output", "pins": ["R1.2", "U2.3"]},
    {"id": "unused", "pins": ["U2.4"]}
  ]
}
```

`id` 可省略，仅供人查看，不参与比较。`pins` 必须非空，每个引脚在整个文件中恰好出现一次；两份导出的命名规范和覆盖范围必须一致。不要按网络名给不同引脚起相同名字。

```text
python scripts/compare_connectivity.py expected.json visible.json --report design_vs_visible.json
python scripts/compare_connectivity.py visible.json native.json --report visible_vs_native.json
```

脚本路径相对于本 skill；调用时解析为实际绝对路径。退出码 `0` 表示分组相同，`1` 表示差异，`2` 表示输入或文件错误。报告列出缺失/新增引脚、网络分裂、网络合并和连接关系变化。

**该脚本不读取 `.ms14`，不自动提取几何，不证明模型没有隐藏绑定，也不运行仿真。** 必须根据当前软件的实际导出方式取得两份独立数据，并另外完成几何审查和动态断线试验。不要把脚本通过描述成完整接线验收通过。

## 断线试验

在已保存的测试副本中选择没有备用路径的关键线路，记录断线前的网络分组及响应。断开后重新取得原生网表，并用能暴露该连接依赖的输入和必要的复位/重新运行观察响应；恢复线路后应恢复原结果。

优先覆盖跨模块数据、时钟或复位等关键连接。锁存器可能保留旧显示，悬空输入可能不确定，因此不能只以“数码管立即熄灭”判断。先证明网络确实断开，再使用可重复的刺激检查对应传输行为。抽样试验结合全图结构检查，不宣称抽查覆盖所有故障。
